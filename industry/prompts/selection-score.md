## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在什么时候，做了什么，处于传闻、征求意见、正式发布、获批还是生效执行阶段”。然后从以下 7 类中选择最贴近的一类：

- `company_filing`：上市公司定期报告与临时公告本身
- `capital_deal`：股权与资产层面的交易动作
- `policy_regulation`：政策、监管动作与规则变化
- `market_shift`：市场整体或板块层面的行情变动
- `data_release`：官方统计数据的发布
- `opinion_view`：重点人物的观点、判断与访谈
- `research_explainer`：研报、综述、数据解读与投资科普

优先级：定期报告与临时公告选 company_filing；交易动作选 capital_deal；政策监管动作选 policy_regulation；纯行情现象选 market_shift；官方数据发布选 data_release；人物发言选 opinion_view（观点为本质时）；研报/解读/科普选 research_explainer。发了业绩又谈了很多观点的调研纪要，按核心事件判。

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在市场时间线上是节点、这周值得知道的变化，还是当天脚注。不要把“有人马上能交易”重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新事实、新数字、新口径、新因果，而不是标题看起来有多新。具体的新业绩、新利率、新政策条款、新价格、新矛盾才是增量。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。交易所公告、监管文件、官方统计足以证明“披露、发布、处罚、调整”这一动作，但不能自动证明其中的盈利预测、目标价或宣传中的效果。
4. `reson` 共振面：多少 {{siteName}} 读者会觉得与自己有关（持仓、行业、政策、生活成本），或至少能理解它为何重要、反常、罕见。
5. `act` 可马上使用：读者是否能马上调整仓位、校准预期、更新研究框架或学走一套方法。研报与解读的 act 高是正常的，纯新闻的 act 低也是正常的，不应反过来抹掉 sig。

### 三、使用以下类型权重合成分数

内部按下表计算 `attentionScore = sig×w1 + nov×w2 + cred×w3 + reson×w4 + act×w5`。每行权重之和为 10，所以结果天然位于 0–100。

| capital_deal | 3 | 2 | 2 | 2 | 1 |

不要把五轴先求平均；不要改权重；不要把多个普通理由堆成高分；不要为了靠近整十或任何想象中的门槛而改写计算结果。

## 品味规则

### 必须正常评价的价值

- 货币政策与流动性操作：降准降息、LPR 调整、公开市场大额投放与到期、再贷款与结构性工具、汇率与外汇储备的重要变化，方向和幅度明确就按节点事件评价。
- 资本市场制度变革：注册制、退市、减持、再融资、交易机制、印花税、对外开放等规则变化，影响全部市场参与者。
- 业绩暴雷或大幅超预期：预告、快报、正式报告中营收利润、现金流、毛利率显著偏离市场共识的披露，以及由此产生的风险或重估。
- 数据大超预期：CPI/PPI、PMI、社融、进出口、GDP、消费与投资等官方数据明显偏离共识或前值时，`nov` 与 `sig` 按真实份量给，不因“只是数据”压低。
- 影响中国市场的海外事件：海外央行的利率决议与表态、关税谈判与反制、地缘冲突、外围市场大幅波动、黄金原油等大宗商品价格异动。
- 重点人物的清晰信号：金融监管负责人、企业家、知名投资人、经济学家给出的可验证的新判断、新数字、新承诺或可观察的市场行为。
- 可信的新事实、反直觉结果、行业供需拐点、监管处罚与风险暴露，只要读者一眼能理解“为什么与自己有关”，可以形成独立高价值。
- 研报与解读按真实份量评价：带新数据、新口径、可核验推论的年度策略与数据解读，不因“不是新闻”被压低；`research_explainer` 的 `act` 可以很高。
- 政策组合拳与国家队动向——金融、货币与资本市场的一揽子政策转向（2024 年 9 月 24 日一揽子金融政策这类级别的），央行、证监会、汇金的盘中表态，国家队（中央汇金等）增持 ETF 的公开公告与动向：这类事件对这位读者是最高档，`sig` 与 `act` 可以拉满，不要被日常公文体裁压低。
- A 股公司公告中的机会型披露：重大合同与订单、回购与增持、股权激励、并购重组与实控人变更，按披露的具体数字与基本面变化评价，不因是“日常披露”压低。
- 资本运作与资金动向：定增与融资定价、重要股东增减持、大宗交易、两融余额与北向资金变化。单条日常播报可低分，但出现方向性变化时按资金信号评价。
- 行业景气与趋势信号：重点板块的产量、价格、库存、开工率等高频数据的趋势变化，供需拐点，板块主线的形成与瓦解。读者据此判断趋势，按真实份量评价。
- 财报窗口期（4 月末、8 月末、10 月末）：同行业第一份显著改变预期的定期报告，或使市场重估行业的首份数据，按节点事件评价。

### 必须压住的噪声

- 荐股软文、喊单、拉群、诱导开户入金、“牛股推荐”与付费策略，无论包装成复盘、早报还是内幕消息，`sig ≤ 2` 且 `act ≤ 2`。
- 课程广告、训练营、付费社群、券商与 App 拉新活动，`sig ≤ 2`。
- 没有数据支撑的复盘、玄学式“悟道”、情绪化喊盘式复盘，`sig ≤ 3` 且 `nov ≤ 3`。
- 传闻、匿名知情人士的单方说法、“据悉”式消息，`cred ≤ 3` 且 `sig ≤ 4`；只有当事方或权威文件确认后，才按正式事件评价。
- 无焦点早报、日报、周报、资讯合集等多事件打包且没有单一焦点，`sig ≤ 3`；只把其中最强的一条当事件时，按那一单独评分。
- 流水播报式的行情速报、收盘播报、涨跌家数罗列、板块排名堆砌而没有一条具体变化，`sig ≤ 3`。
- 例行小版本式披露：只换措辞的投资者关系问答、无实质变化的例行公告、纯人事简历、常规分红时间表，`sig ≤ 3`。
- 营销软文、概念关联（“某公司也涉及某热点”）、模糊路线图、限免与拉新，`sig ≤ 2`。
- 只有意向书、框架协议、战略合作，没有金额、股权比例、时间表与可验证内容，`nov ≤ 3` 且 `cred ≤ 4`。
- 宏大观点若没有新事实、新因果或可复用框架；融资、估值、会面、成立委员会若没有已兑现后果；均应明显低分。
- 纯短线资金与情绪噪音：龙虎榜与席位榜、游资动向、涨停复盘、日内情绪与无基本面支撑的题材炒作，对中长线读者无用，`sig ≤ 4`。同一条新闻若同时含有基本面变化（如龙虎榜反映产业资本真实增持或政策信号），按基本面部分评价，不因题材外衣压低。
- 转述、摘编、翻译或二手报道，若只是重复已有信息而没有新增事实，`nov ≤ 3`。
- 与 A 股无传导的海外日常新闻：美股个股涨跌、海外公司日常动态、无 A 股板块映射的海外政策，`sig ≤ 4`；属于系统性事件（全球黑天鹅、美元体系级变化）或能明确落到 A 股具体板块（AI 主线传导到算力与半导体链、美联储动作传导到贵金属与出口链）的，不适用本条。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的效果、因果或阶段补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，最终分数不得高于 30。
- 如果只能确认“有人声称某事”，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强故事。
- 阶段口径：同一事项在不同阶段的证据强度不同，必须按原文写明的阶段评价，不许把早期阶段当成已落地。传闻/意向 `cred ≤ 3` ＜ 征求意见/草案 `cred ≤ 4` ＜ 审议通过/正式发布 ＜ 获批/注册生效 ＜ 生效执行。原文没写阶段时按材料能支持的最弱阶段评，不因标题用了“落地”“开征”“已实施”就升级。
- 预期差口径：数据与业绩的价值在“相对预期”，不在“数字大”。符合市场共识的披露低于大超预期的披露；不及预期的事实是“低于共识”，不是“没有发生”。原文只给数字、不给预期值与前值时，按常规发布评分，不得替它补一个“爆表”或“暴雷”的故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 广泛覆盖本身是实质变化。一项面向全市场或全行业的政策、一轮影响全部账户与费率的规则调整、一个被大量投资者使用的交易或数据入口，若把明确变化正式推出并给出执行时间，这是影响面和现实影响的变化；即使材料是短引用，也不能按“普通转发”或“概念关联”压低 `sig`、`nov`、`reson`。
3. 制度性规则变化（发行、退市、减持、再融资、交易机制、税费）按影响面判断，不按“有没有新产品”判断。若材料还给出受影响的公司数量、资金体量、时间表或行业测算，它同时提供了可理解的影响证据；不得套用“普通概念关联”或“泛泛政策表态”的上限。
4. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。例如“业绩大幅预增 + 一句管理层表态”“降准落地 + 一段市场猜测”，不能只抓住表态或猜测。
5. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、单一内部口径、机构营销或宏大推断制造事件价值。只有正文支持的新事实、政策变化或价格数据进入五轴。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。

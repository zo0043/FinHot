【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：公司名 / 机构名 / 指数或品种名 / 人名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代码 / 编号 / 没信息量的 teaser（如 "600519"、"000858"、"SHMET"、"重要公告"）时，结合【来源】和正文把主体补进标题。例：原标题 "关于回购股份进展的公告" + 来源 "贵州茅台：上交所公告" → "贵州茅台披露股份回购进展"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体公司或机构时，用上位词（如"一家新能源车企""某城商行"）兜底，绝不凭"行业常识"编一个具体公司 / 代码 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Explainer 这类解释、分析、教程、综述或复盘标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的公司、政策或新数据，就改写成“发布 / 推出 / 上线 / 实施”。只有原标题明确宣布了披露、发布、调整或生效，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、政策、指数或人名。
   例：原标题 "How China's rate cuts reach corporate funding costs" → "中国降息如何传导至企业融资成本"，不能写成 "中国央行宣布降息"。
   例：原标题 "What the new delisting rules mean for small caps" + 来源和正文明确是证监会 → "证监会退市新规对小微盘股意味着什么"，不能只写成缺主体的 "退市新规意味着什么"。
